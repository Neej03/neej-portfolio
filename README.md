## 🌟 Overview

Welcome to the official developer portfolio repository for **Neej Butani**. Built from the ground up with **React.js**, **Vite**, and **Tailwind CSS**, this portfolio combines high-performance engineering with rich aesthetics, glassmorphism, micro-animations, and interactive AI capabilities.

### ✨ Key Features

- **🎨 Crimson Obsidian Aesthetics**: High-contrast dark mode design system with smooth Framer Motion spring physics, glassmorphic cards, and custom desktop glow cursors.
- **🌌 Interactive Particle Mesh Canvas**: Custom WebGL/Canvas background mesh reacting dynamically to user cursor velocity and hover force fields.
- **🔊 Native Web Audio API & TTS Voice Feedback**: Real-time synthesized click audio blips and SpeechSynthesis Text-To-Speech (TTS) label voice feedback, controllable via a top header toggle button.
- **🤖 Neej AI Floating Assistant**: Natural language AI assistant widget offering interactive Q&A about skills, projects, experience, and contact details.
- **🚀 19 Production Projects Showcase**: Integrated search bar, real-time category filter pills (`All`, `Full Stack`, `AI & ML`, `Frontend & Design`, `Cybersecurity & Tools`), green `Live App` pulse badges, tech stack counters, and full-screen detail modals.
- **📄 Interactive PDF Resume Viewer**: Embedded in-browser PDF previewer and direct one-click PDF download for the official curriculum vitae.
- **📱 Fully Responsive**: Seamless layout adaptation across mobile, tablet, desktop, and ultra-wide displays.

## ⚡ Getting Started & Local Setup

To run this repository locally on your machine, follow these steps:

### Prerequisites
Make sure you have **Node.js** (v18.0.0 or higher) and **npm** installed on your system.

### 1. Clone the repository
```bash
git clone https://github.com/Neej03/neej-portfolio.git
cd neej-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### 4. Build for production
```bash
npm run build
```
